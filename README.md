AdventureWorks Sales Analysis

Project Overview

This project analyzes AdventureWorks sales data using four data analytics tools: Microsoft Excel, SQL, Power BI, and Tableau. The objective is to explore sales performance, profitability, and business trends through data analysis and visualization.

Tools & Technologies

- Microsoft Excel: Data analysis, PivotTables, and PivotCharts
- SQL: Data querying and analysis
- Power BI: Interactive dashboard development, DAX measures, KPI cards, and data modeling
- Tableau: Data visualization and interactive dashboards

Power BI Dashboard

The Power BI dashboard presents key business performance indicators, including:

- Total Sales
- Total Profit
- Profit Margin
- Total Cost
- Order Count

The dashboard includes Year, Quarter, and Country slicers for interactive analysis.

Data Modeling

A star schema was implemented for the Power BI data model to support organized relationships and efficient analysis.

Project Highlights

- Analyzed business data using multiple analytics tools.
- Developed dashboards and visualizations to communicate insights.
- Created KPIs and used DAX measures for business performance analysis.
- Used PivotTables and PivotCharts for exploratory analysis in Excel.
- Applied SQL queries to investigate the data.
- Explored business trends through Tableau visualizations.
